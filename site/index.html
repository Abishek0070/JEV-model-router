// 01 — Install

Two commands. Zero config.

One JEV key unlocks intelligent routing. One LLM key unlocks generation. No keys at all? The local heuristic and mock provider keep you moving.

operator@mainframe:~
$ npm i jevrouter-ai
$ npx jevrouter-ai init # scaffolds config + .env, asks for JEV key
$ npx jevrouter-ai start # gateway live on :4000/v1
$
// 02 — Routing tiers

JEV thinks in tiers, not models.

Every request gets a capability verdict with calibrated confidence. Low confidence escalates one tier automatically. Swap providers anytime — JEV never needs retraining.

FAST

Greetings, summaries, simple lookups. Milliseconds matter more than muscle.

  • groq-llama
  • gemini-flash

BALANCED

Debugging, refactors, everyday engineering. The workhorse tier.

  • gpt-mini
  • claude-haiku

POWERFUL

Proofs, outages, distributed design. Reserve the frontier for the frontier.

  • claude-sonnet
  • gpt-reasoning
// 03 — Pipeline

Eight stages. Full telemetry.

JEV latency is tracked per stage and reported separately — provider inference is never hidden inside routing numbers.

01
INGRESSOpenAI POST /v1/chat/completions (stream + tools) · Anthropic POST /v1/messages · in-process router.chat()
02
EXACT CACHESHA-256 over messages + params + tools. Hit → instant reply, original tier preserved.
03
JEV DECISIONjevmodel → typesafe → openrouter → local failover, circuit breakers. Returns fast | balanced | powerful + confidence.
04
POLICY ENGINEtier ∩ route.allow minus over-budget models. Your rules, your money.
05
MODEL SCORINGscore = w·quality − w·cost − w·latency, weighted by route priority.
06
DISPATCHERRetries with backoff on 429/5xx only. Falls over to the next model, then the next tier.
07
PROVIDERSOpenAI · Anthropic · Gemini · Groq · Ollama · Mock. BYOK, keys never leave the gateway.
08
TELEMETRYEvery request: tier, confidence, model, cost, latency split, fallback, cache. Always know why.

// 04 — Interface

Speak your protocol.

Point any OpenAI-compatible client at the gateway, or embed the router in-process. Dry-run routing decisions for free before spending a token.

ENDPOINTS

POST/v1/chat/completionsmodel: "auto" routes via JEV · stream: true → SSE
POST/v1/messagesAnthropic ingress for Claude Code + SDKs
POST/v1/routing/decisiondry-run: tier + ranked candidates, zero LLM spend
GET/v1/models · /health · /ready · /v1/telemetry/recentdiscovery, probes, decision log
